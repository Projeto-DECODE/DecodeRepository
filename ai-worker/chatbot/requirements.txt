# Cada biblioteca tem a versão EXATA (==). Assim, a EC2, o seu
# computador e o CI instalam sempre as mesmas versões, e uma
# atualização nova de um pacote não quebra o chatbot sem aviso.
#
# As versões vêm do requirements.lock, que registra o que está
# realmente instalado e funcionando na EC2 (131 pacotes, contando
# as dependências das dependências). Aqui ficam só as 15 que o
# nosso código usa diretamente.
#
# O PyTorch (torch) NÃO está aqui de propósito: ele é instalado
# ANTES, na versão só para CPU, conforme o GUIA_EC2_DECODE.md
# (Parte 5.2). Instale com:
#   pip install --no-cache-dir -r requirements.txt
#
# Para atualizar uma versão: teste o chatbot com a versão nova,
# troque o número aqui e atualize o requirements.lock.
